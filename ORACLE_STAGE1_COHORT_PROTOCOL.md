# CHARIS V2 Oracle Stage 1 — Cohort Protocol

Diagnostic only. The primary frozen V2 model, preprocessing, scoring, and cohort result are not changed by this analysis. This stage estimates an upper bound on performance obtainable from limited patient-specific calibration.

## Provenance

- Primary workflow run: `33218500889`
- Primary commit: `3a68ed7fdb0108d0fdaeb686c3783bbdf2726455`
- Inputs: frozen blind artifacts (`blind-charis1` ... `blind-charis13`) and already-unlocked paired scoring artifacts (`score-charis1` ... `score-charis13`) from that run.
- No raw ICP is re-read by this oracle workflow; the paired 1-Hz reference generated by the frozen scoring stage is reused.

## Stage 1 hierarchy

1. Offset-only oracle: MAE-optimal additive offset = median(reference - V2 prediction).
2. `R_o`-only oracle: 80 log-spaced multipliers from 0.1x to 20x the frozen population `R_o=526.3 mmHg*s/mL`; select by MAE.
3. `R_o + offset` oracle: at each same `R_o` candidate, compute the MAE-optimal offset; select the pair with lowest MAE.

Whole-record fits are nondeployable diagnostic upper bounds.

## Early-fit -> late-predict transfer

Chronologically sort the already paired score-eligible rows. The first 25% is development and the remaining 75% is test. Fit offset and/or `R_o` only on development and apply them unchanged to the late test period. No segment-specific fitting is allowed.

## Fast mechanistic replay

The equations and population parameters are unchanged. To make the 80-candidate profile practical across the cohort, the frozen blind artifact's 1-Hz `A_map_mmHg` and `A_dot_mmHg_s` are replayed with cubic-Hermite interpolation between adjacent 1-Hz samples and classical RK4 with two 0.5-s substeps. Segment initialization remains `P0=9.5 mmHg`, `C0=C_an`.

Before any oracle result is accepted for a patient, an exact-population `R_o` replay is compared with that patient's stored frozen primary V2 prediction. Acceptance requires mean absolute replay error <=0.02 mmHg, 99th percentile <=0.15 mmHg, and maximum <=0.5 mmHg. A failure aborts that patient job rather than silently changing the method.

On CHARIS6 this replay reproduced the previously frozen Stage-1 results to approximately 0.002 mmHg in MAE and <0.001 mmHg in the fitted offset; this check validates computation only and does not alter the oracle grid or objective.

## Interpretation

Oracle results are not deployable performance and must not replace the primary blind cohort result. A large whole-record improvement with poor early-fit -> late-predict transfer indicates nonstationarity/overfitting rather than a clinically usable calibration strategy. Frequent selection of a grid boundary is reported explicitly as evidence of weak identifiability/profile behavior.

Stage 2 (`P0, R_o, k_E, G`) is not part of this run and requires a separate freeze after Stage 1 is inspected.
